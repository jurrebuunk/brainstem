# @brainstem-dev/plugin-opencode-runner

Start an opencode session for a decision (a coding agent).

A [Brainstem](https://github.com/jurrebuunk/brainstem) destination plugin.

## Install

```sh
brainstem plugins add @brainstem-dev/plugin-opencode-runner
```

## Use

```js
destinations: [{
  id: "my-opencode-runner",
  module: "@brainstem-dev/plugin-opencode-runner",
  config: { /* see the documentation */ }
}]
```

Configuration and examples: [docs/plugins/opencode-runner.md](https://github.com/jurrebuunk/brainstem/blob/main/docs/plugins/opencode-runner.md).
