# @brainstem-dev/plugin-github-issues

Turn new and updated GitHub issues into observations.

A [Brainstem](https://github.com/jurrebuunk/brainstem) input plugin.

## Install

```sh
brainstem plugins add @brainstem-dev/plugin-github-issues
```

## Use

```js
inputs: [{
  id: "my-github-issues",
  module: "@brainstem-dev/plugin-github-issues",
  config: { /* see the documentation */ }
}]
```

Configuration and examples: [docs/plugins/github-issues.md](https://github.com/jurrebuunk/brainstem/blob/main/docs/plugins/github-issues.md).
