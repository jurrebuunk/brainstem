# @brainstem-dev/plugin-log-decisions

Log decisions to the console.

A [Brainstem](https://github.com/jurrebuunk/brainstem) destination plugin.

## Install

```sh
brainstem plugins add @brainstem-dev/plugin-log-decisions
```

## Use

```js
destinations: [{
  id: "my-log-decisions",
  module: "@brainstem-dev/plugin-log-decisions",
  config: { /* see the documentation */ }
}]
```

Configuration and examples: [docs/plugins/log-decisions.md](https://github.com/jurrebuunk/brainstem/blob/main/docs/plugins/log-decisions.md).
